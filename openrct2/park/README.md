# Initial park

Put **one** park file here (`.park`, `.sv6`, `.sc6`, `.sv4` or `.sc4`). It is used
only for the very first start, when no saves exist yet. After that the server
always resumes from the newest save. With several files, set `INITIAL_PARK` in
`.env` to the file name.

Park files are not committed to git (see `.gitignore`).
